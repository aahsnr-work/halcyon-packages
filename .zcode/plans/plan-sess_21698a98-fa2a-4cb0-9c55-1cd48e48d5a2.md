# Three new packages: onlyoffice-desktopeditors, marksman, texlab

Research base: ONLYOFFICE officially ships a 363 MB vendor RPM (v9.4.0, /opt layout, bundled Qt5+CEF, AGPLv3, no metainfo; upstream repo is ONLYOFFICE/DesktopEditors — AppDesktopEditors is gone); marksman ships bare self-contained .NET 9 release binaries under date tags (no crates.io — the name is squatted; MIT; needs libicu); texlab is a clean pure-Rust workspace on GitHub (crates.io stale at 4.3.2 → the yazi GitHub-tarball pattern applies; GPL-3.0; Cargo.lock committed, `--locked`-safe). None are in Fedora. Decisions locked: ONLYOFFICE = bitwarden-style vendor-RPM rewrap published on the **R2 wave** (user choice — keeps 363 MB out of the 1 GB Pages budget); texlab = **Rust source build** (yazi pattern; also the latest version). All three get the 4-file treatment plus two small CI edits.

## 1. onlyoffice-desktopeditors — batch 4 (R2 wave), bitwarden pattern
`anda/onlyoffice-desktopeditors/{onlyoffice-desktopeditors.spec, anda.hcl, update.rhai}`:
- Spec modeled on `anda/bitwarden/bitwarden.spec`: `%global debug_package %{nil}` + the full byte-identity brp-hook unset set (strip/strip_comment_note/strip_lto/static_archive/mangle_shebangs nil, add_determinism undefine); `__provides_exclude_from ^/opt/onlyoffice/` and a `__requires_exclude` for bundled sonames (libQt5*, libcef, bundled icu/gst — exact pattern validated in the fix loop against `rpm -qp --requires` so only system deps remain, matching the vendor RPM's 22-entry Requires list).
- `#!RemoteAsset Source0:` the vendor RPM `https://github.com/ONLYOFFICE/DesktopEditors/releases/download/v%{version}/onlyoffice-desktopeditors.x86_64.rpm`; `Source1` = curated AppStream metainfo `org.onlyoffice.desktopeditors.metainfo.xml` committed in the package dir (copied from Flathub's CC0 file — vendor ships none, bitwarden precedent).
- `%prep`: `rpm2cpio | cpio -idmu`. `%install`: `cp -a opt usr` into buildroot, install metainfo, fix the vendor desktop-file Exec `%U` → `%F` (documented file-opening bug, AUR gotcha). `%check`: desktop-file-validate. `%files`: `/opt/onlyoffice/`, the two `/usr/bin` entries, desktop file, hicolor icons, licenses from the payload (verify path in the fix loop; else fetch the AGPL text as an extra Source).
- Explicit `Requires:` parity with the vendor's runtime-only declarations (dejavu + liberation fonts, xdg-utils, libnotify, libXScrnSaver).
- `update.rhai`: `rpm.version(gh("ONLYOFFICE/DesktopEditors"))` (v-prefixed tags; gh() strips v).
- CI: generalize `build4` in anda-build.yml from the hardcoded `anda build anda/texlive-texmf` to a matrix-driven wave like build0–3 (matrix.py already emits texlive as `anda/texlive-texmf/pkg`), so batch 4 = texlive-texmf + onlyoffice-desktopeditors, published by the existing `publish4` (target r2). Update the batch-4 comment in packages.toml.

## 2. marksman — batch 0, release-binary wrapper
- Name marksman; `Version: 2026.02.08` (date tags converted to dots); License MIT; ExclusiveArch x86_64.
- `%global markstag 2026-02-08`; `#!RemoteAsset Source0:` `.../releases/download/%{markstag}/marksman-linux-x64` (bare self-contained .NET 9 binary); `#!RemoteAsset Source1:` the repo LICENSE at the same tag (release assets carry no license).
- `%install`: binary to `%{_bindir}/marksman` (port the tealdeer/opencode wrapper shape). `Requires: libicu` (self-contained .NET dlopens ICU; not DT_NEEDED-visible). No desktop file (LSP server).
- `update.rhai`: `let tag = gh("artempyanykh/marksman"); rpm.global("markstag", tag); rpm.version(sub("-", ".", sub("-", ".", tag)));` — sub() semantics verified in the fix loop (fallback: three find() calls).

## 3. texlab — batch 0, Rust source build (yazi pattern)
- Name texlab; Version 5.26.0; `Source0` GitHub tag tarball `.../archive/refs/tags/v%{version}.tar.gz` (GitHub names the dir texlab-5.26.0 — v-stripped, yazi precedent); License `GPL-3.0-only AND <aggregate>` — the aggregate filled from `cargo_license_online` output at implementation time (yazi/gen-final approach).
- BRs: cargo, anda-srpm-macros, cargo-rpm-macros >= 24, mold, sccache. `%autosetup` → `%cargo_prep_online_sccache` → `%cargo_build` (SCCACHE_DIR export; add a vergen-style env only if the build script demands git info — checked in the fix loop) → install `target/rpm/texlab` to bindir; `LICENSE.dependencies` via `%cargo_license_online`. Pure-Rust deps (no openssl/protoc), lockfile committed → `--locked`-safe; edition 2024 needs rust ≥ 1.85, F44 is newer.
- `update.rhai`: `rpm.version(gh("latex-lsp/texlab"))`.

## Registry + validation
- ci/packages.toml: `[marksman] batch = 0`, `[texlab] batch = 0`, `[onlyoffice-desktopeditors] batch = 4` with a comment explaining the R2 placement (363 MB); comment style follows the existing entries.
- Validation in the fix loop, one local podman build at a time: marksman → texlab → onlyoffice; each spec validated against the real upstream artifact per the repo rule. Then commit + push (runs queue behind run 24 automatically).

Everything lands as the standard 4 files per package plus the one workflow edit — no mock/builder changes, no new secrets.
